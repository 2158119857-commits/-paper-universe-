# 一页纸的宇宙 · Powers of Ten

从一粒沙出发，一路后退 28 个数量级，直到可观测宇宙的边缘。
11 张真实影像串成一条连续的尺度轴；其中三站可以走进去，变成真正的三维场景；其余每一张照片也被深度图抬起，成为会随指针转动的三维曲面。

- **在线作品**：https://2158119857-commits.github.io/-paper-universe-/
- **仓库**：https://github.com/2158119857-commits/-paper-universe-
- **课程**：《解密DeekSeek：从基础到创意实践》课程大作业
- **形式**：单文件 WebGL 交互网页（无框架、无第三方库、无 CDN）

## 一、作品简介

尺度是人类直觉的盲区：我们能想象一条街的长度，却无法想象 10²⁶ 米。
这个作品不解释数字，而是让人**连续地退后**——每一帧都比上一帧远一点，直到沙粒变成星系。

| # | 站点 | 尺度（米） | 影像来源 |
|---|---|---|---|
| 1 | 一粒沙 | 3 × 10⁻² | NASA / JPL-Caltech / MSSS（好奇号 MAHLI） |
| 2 | 沙丘与海岸 | 5 × 10³ | NASA / JPL-Caltech / USGS |
| 3 | 城市夜色 | 6 × 10⁴ | NASA / ISS Expedition 25 |
| 4 | 海岸与群岛 | 5 × 10⁵ | NASA / ISS Expedition 71 |
| 5 | 地球 | 1.3 × 10⁷ | NASA / Suomi NPP「蓝色弹珠」 |
| 6 | 地月系统 | 1.2 × 10⁹ | NASA / Apollo 17「地球升起」 |
| 7 | 太阳 | 3 × 10⁹ | NASA / SDO（AIA 171） |
| 8 | 恒星的世界 | 6 × 10¹⁸ | NASA / JPL-Caltech（半人马座 ω） |
| 9 | 银河系 | 1 × 10²² | NASA / JPL-Caltech（艺术想象图） |
| 10 | 宇宙网 | 3 × 10²⁵ | NASA / ESA / STScI（星系团） |
| 11 | 可观测宇宙 | 8 × 10²⁶ | NASA / ESA / STScI（哈勃深场） |

## 二、核心功能

1. **连续尺度轴**
   滚轮、拖拽、方向键都能改变 `log10(米)`；11 站的影像按距离交叠。站与站之间另有一层满屏「穿越层」：离开一站时朝本图热点推近放大，下一站从同一点展开，中间不露星空，也不会出现悬浮的小卡片。

2. **三个可进入的三维站台**
   - 地球轨道：昼夜光照球体、独立云层、月球公转、杭州定位点
   - 太阳系：自发光太阳、八颗行星、土星环、可点击的天体信息
   - 银河系：粒子旋臂、银心、太阳位置标记

3. **静态照片的三维化**
   每张照片配一张单目深度图（Depth Anything V2 生成），渲染时：
   - 顶点按深度抬起，形成约 1 万个三角面的曲面
   - 指针带动曲面轻微旋转，产生真实透视视差
   - 用深度邻域计算环境光遮蔽与方向光，山脊和沙粒有明暗
   - 高光呼吸、云层漂移、星野慢转

4. **跨越数量级的叙事**
   大跨度段落（太阳 → 恒星 9.6 个数量级）不切黑场，而是：
   - 旧图放大送出、新图从 1.16 倍收回的「推镜」
   - 顶部对数尺随尺度滑动，实时读数 `1.6 × 10¹⁴ 米`
   - 中央巨号量级水印，每跨一个数量级浮现一次
   - 从画面中心向外的速度线

5. **五个程序化重建场景**
   沙粒 / 沙丘 / 城市 / 恒星 / 宇宙网五站，左下角出现「进入重建 →」，打开后是独立页面里的实时三维场景：
   - 沙粒：903 颗噪声形体沙粒，阴影贴图、扫描动画、悬停提示、点击隔离
   - 沙丘：多层噪声地形，迎风缓坡与背风陡坡，海平面与水面高光
   - 城市：上千个体块，窗格灯光按世界坐标计算
   - 恒星：四万颗按密度函数分布的恒星点阵
   - 宇宙网：节点与最近邻纤维，附小星系点阵
   返回后停在原来的尺度位置，不打断旅程。

6. **交互与分享**
   热点标注、信息抽屉、自动播放、空格暂停、`#u=14.2` 这样的尺度深链、移动端适配。

## 三、技术实现

- **渲染**：原生 WebGL 1/2，自写透视投影、lookAt、球体/圆环/网格几何与 9 组着色器，无 Three.js 等库
- **深度**：离线用 `onnxruntime` 跑 Depth Anything V2 (small, ONNX) 生成 15 张深度图，运行时只加载灰度图
- **几何**：96 × 54 网格，顶点着色器读取深度贴图并沿视线抬升
- **兼容**：WebGL 不可用时自动降级为 2D 版本提示；设备不支持顶点纹理采样时自动关闭曲面
- **性能**：影像与深度图按当前站 ±2 懒加载；移动端贴图上限 1024px

## 四、运行方法

纯静态站点，任选其一：

```bash
# 方式 1：任意静态服务器
python -m http.server 8080

# 方式 2：项目自带（需要 bun）
bun run serve.js
```

然后打开 <http://localhost:8080>。

> 直接双击 `index.html` 也能运行，但部分浏览器会限制本地纹理读取，建议用静态服务器。

## 六、制作过程与 AI 工具

全程在 **Cherry Studio** 中与 AI 结对完成，使用的 AI 能力：

- 对话式编程（Claude）：需求拆解、WebGL 引擎与着色器编写、调试、文档
- 单目深度估计（Depth Anything V2 small，本地 ONNX 推理）：为每张照片生成深度图
- AI 图像/素材：无。所有画面均为 NASA / ESA 公共领域影像

制作流程：选题与概念 → 首版（插画风）→ 用户反馈「太卡通」→ 换真实 NASA 影像 → 反馈「可互动性弱」→ 加入 WebGL 与三维站台 → 热点定位、移动端、部署 → 转场与跨尺度叙事 → 深度三维与动态化 → 五个程序化重建场景 → 站间穿越层。

完整交互记录见提交材料中的《AI 交互记录》。

## 八、已知限制

- 单张照片只能恢复「浮雕式」三维，无法绕到物体背面
- 深空影像的深度由模型推断，星空部分的三维感有限
- 银河系一站为基于观测数据的艺术想象图，非实拍
- 低端移动设备在高分辨率下可能掉帧
